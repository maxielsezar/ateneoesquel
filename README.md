## Sorteos de Instagram

La ruta `/sorteo` carga comentarios y respuestas mediante la Instagram Graph API. Para habilitarla, configurá en `.env.local` las variables de `.env.example` con el ID de una cuenta profesional de Instagram y un token de usuario emitido para esa cuenta. La app de Meta debe tener los permisos `instagram_business_basic` e `instagram_business_manage_comments`. El token se usa únicamente en el servidor; no lo publiques ni lo envíes desde el navegador.

La API solo puede consultar publicaciones de la cuenta profesional conectada y devuelve los comentarios que Meta permita leer para esa cuenta.
